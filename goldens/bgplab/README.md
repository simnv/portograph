# bgplab sheets

44 sheets authored from the [bgplab](https://github.com/bgplab/bgplab) labs (commit `4bd74dbc7f19f172d51cda9ff681303f7e152a5a`, MIT, Ivan Pepelnjak). They are inputs only: no render is committed, and `npm run corpus` lays out each of them. The sheet header names the source, the reference drawing, and what was kept, added, simplified and dropped. The manifest in [`ref/corpora/bgplab/manifest.md`](../../ref/corpora/bgplab/manifest.md) has one row per lab (44 admitted, 10 aliases of these sheets, 2 pending), the recipe and the upstream licence.
